    How a score gets on the board

    Every AUTO played to 0:00 is recorded, for each alliance running a team's own code. It counts for Top AUTO when every robot on it runs its team's own uploaded code and has a team number, the hive tip rules are the standard ones, the parking zones haven't been moved, and no robot on it crosses onto the other alliance's side (G402, a MAJOR FOUL – warnings such as bumping the hive frame, G417, don't count). Set every robot setting – timings, accuracy, drivetrain, camera, shooter, error – to whatever your robot really does: they never keep a score off the board. Code marked @sim preloads-score and hand-written sim scripts don't count.

    Only the team numbers, the score, a fingerprint of the code and whether it counts are sent – never the code. Each team (or pair of teams) shows its best score. The board updates every few minutes.

      Translate into

      This browser doesn’t have the built-in translator the simulator uses (it’s in Chrome on a computer). You can still use your browser’s own translation:

      • Chrome: right-click the page → Translate to…
      • Edge: right-click the page → Translate to…
      • Safari: click the translate icon in the address bar (or View → Translation)
      • Firefox: click the translate icon in the address bar (or the ☰ menu → Translate page)

      🔒 Code you paste or upload here is not saved and never leaves this computer – it is cleared when the page is reloaded or closed.

      Reads: Pedro Pathing 3 (PoseFactory, line/curve, Ivy sequential(follow(…))), Pedro Pathing 2 (BezierLine, switch (pathState)), Road Runner 1.0, and the FTC SDK sample autos (encoderDrive, driveStraight/turnToHeading/holdHeading, timed setPower). Anything else: use Translate on the robot card, or upload a robot log (.csv).

      Selecting several files at once (for example your BiobuzzAutoBase plus the OpMode) reads them together. Add // @sim shoot, // @sim intake on, // @sim wait 1.5 or // @sim start -63 -40 0 comments anywhere the simulator can’t tell what a line does.

      What the simulator will run

          Translate your code

          The simulator reads your code without running it. Most of it is understood automatically – here you only answer the calls it can’t work out, like your own robot.driveToGoal() or a custom command. Your answers are added to what it already reads. Like your code, they are not saved – they are cleared when the page is reloaded. For an exact replay of what your robot really did, record a log with SimRecorder.java and upload the .csv.
