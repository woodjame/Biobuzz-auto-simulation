    How a score gets on the board

    Every AUTO played to 0:00 is recorded, for each alliance running a team's own code. It counts for Top AUTO when every robot on it runs its team's own uploaded code and has a team number, the game settings are the standard ones (camera, robot size and RP settings may change), the parking zones haven't been moved, no robot on it crosses onto the other alliance's side (G402, a MAJOR FOUL – warnings such as bumping the hive frame, G417, don't count), and the robot cards keep realistic times (flower pull 0.75 s or more, garden pickup 0.5 s or more, launching 4 takes 0.6 s or more) and the accuracy setting isn’t changed. Code marked @sim preloads-score and hand-written sim scripts don't count.

    Only the team numbers, the score, a fingerprint of the code and whether it counts are sent – never the code. Each team (or pair of teams) shows its best score. The board updates every few minutes.

      Selecting several files at once (for example your BiobuzzAutoBase plus the OpMode) reads them together. Add // @sim shoot, // @sim intake on, // @sim wait 1.5 or // @sim start -63 -40 0 comments anywhere the simulator can’t tell what a line does.

          Translate your code

          The simulator reads your code without running it. Most of it is understood automatically – here you only answer the calls it can’t work out, like your own robot.driveToGoal() or a custom command. Your answers are added to what it already reads. Like your code, they are not saved – they are cleared when the page is reloaded. For an exact replay of what your robot really did, record a log with SimRecorder.java and upload the .csv.
